# Sigil Contracts

Solidity contracts for the Sigil single-tier identity registry. Built with Foundry,
pinned to Solidity 0.8.28 (`foundry.toml`), targeting Base Sepolia (84532) and
Base mainnet (8453); local dev runs on anvil (31337).

## Layout

```
src/
├── SigilRegistry.sol             Single-tier registry — immutable after deploy.
│                                 Talks to the generated UltraHonk verifier directly via
│                                 an inline IUltraHonkVerifier interface; BN254 reduction
│                                 + public-input marshalling live in a private helper.
├── CSCAMerkleTree.sol            Holds the ICAO CSCA Merkle root (Ownable2Step).
├── interfaces/
│   └── ISigilRegistry.sol        Protocol-integration surface (isVerified, nullifierOf, ...).
└── verifiers/
    └── SigilUltraHonkVerifier.sol  Auto-generated by `bb write_solidity_verifier`.

script/
├── Deploy.s.sol                  Production deploy (real verifier, real CSCA root).
└── DeployDev.s.sol               Anvil deploy (MockUltraHonkVerifier — accepts any proof).

test/
├── SigilRegistry.t.sol
├── CSCAMerkleTree.t.sol
└── mocks/MockUltraHonkVerifier.sol
```

## Trust model

The registry is **immutable** — no governor, no setters, no pause, no successor.
Parameters (`registrationTTL`, `maxDailyRegistrations`) and dependency addresses
(`verifier`, `cscaMerkleTree`) are constructor immutables.

The **only privileged action** in the system is `CSCAMerkleTree.setRoot`. The CSCA
tree is `Ownable2Step`; initial owner is the deployer EOA, MUST be transferred to a
multisig / TimelockController before mainnet. See "Production deploy procedure" in
the repo root `CLAUDE.md`.

make contracts-test        # forge test -vvv

## Deploy

```bash
# Base Sepolia (testnet) — see Deploy.s.sol header for full setup
forge script script/Deploy.s.sol:Deploy \
  --rpc-url base_sepolia --account base_sepolia --broadcast -vvvv

# Local anvil with MockUltraHonkVerifier
make anvil-deploy
```

## Contract architecture (one paragraph)

`register(nullifier, epochNullifier, passportExpiry, proof)` checks the passport
isn't expired, that this wallet isn't already actively registered, that the
per-passport per-day rate limit isn't hit, and that the ZK proof verifies against
the current CSCA root. On success it appends the wallet to the nullifier's
wallet array, sets `expiresAt = min(now + ttl, ceil(passportExpiry / 90 days) * 90 days)`,
sets `nullifierByWallet[hash(wallet)] = nullifier`, and emits `WalletVerified`.
`renew` refreshes `expiresAt` for an existing wallet (skipping the rate limit).
`unregister` removes the caller from the registry. Read-side: `isVerified(wallet)`,
`nullifierOf(wallet)`, `getExpiry(wallet)`, `getRegisteredAt(wallet)`,
`getWallets(nullifier)`.
